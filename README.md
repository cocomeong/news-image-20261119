# Sum up 19 November's world news in one image

Entry for make.fun bounty `news-image-20261119` — $250, deadline 21 Nov 2026 00:00 UTC.

`main.ts` (Node 22, stdlib only, no network) copies `entry.png` to
`/output/entry.png`. The image is a fixed 1024x1024 PNG, 990,003 bytes,
so both grader runs write identical bytes.
